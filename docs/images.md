# Images

## Attachments

`Image` wraps an attachment of the media library:

```php
use Dbout\WpFoundation\Image\Image;

$image = Image::fromId(42);
$image = Image::fromValue(get_field('cover'));    // ID, URL, array with an "ID" or "id" key, WP_Post or Image
```

Both return `null` when the attachment does not exist.

| Method | Description |
|---|---|
| `src($size = null)` | URL of the file, of a registered size (`'large'`, ...) or of the original file |
| `srcset($size = 'full')` | `srcset` attribute |
| `width($size = null)`, `height($size = null)` | Dimensions |
| `alt()`, `caption()`, `title()` | Texts of the attachment |
| `mimeType()`, `isImage()`, `isVideo()`, `isSvg()` | Type of the file |
| `path()` | Absolute path of the file |
| `meta($key)` | Post meta of the attachment |

An `Image` is converted to its URL when it is used as a string:

```twig
<img src="{{ image.src('large') }}" srcset="{{ image.srcset('large') }}" alt="{{ image.alt }}" width="{{ image.width('large') }}" height="{{ image.height('large') }}">
```

## Resize and convert

The `resize` and `towebp` Twig filters generate a copy of an image of the media library, next to the source file:

```twig
<img src="{{ image.src|resize(800, 600) }}" alt="{{ image.alt }}">
<img src="{{ image.src|resize(800)|towebp(75) }}" alt="{{ image.alt }}">
```

| Filter | Description |
|---|---|
| `resize(width, height = 0, crop = 'default', force = false)` | A size of 0 is computed from the ratio of the image. `crop` is one of `default`, `center`, `top`, `bottom`, `left`, `right`, `top-center`, `bottom-center`, or `false` to resize without cropping |
| `towebp(quality = 80, force = false)` | WebP copy, the quality is from 0 to 100 |

The same methods are available in PHP:

```php
use Dbout\WpFoundation\Image\ImageResizer;

$resizer = new ImageResizer();
$url = $resizer->toWebp($resizer->resize($image->src(), 800, 600));
```

- The files are generated once, then reused: a file is generated again when the source is more recent, or with `force`.
- The files are named `photo-800x600-c-center.jpg` and `photo-800x600-c-center.webp` (like Timber, so the files generated by Timber are reused).
- The source URL is returned as is for the SVG files and the files outside `wp-content`. When the file cannot be generated, the source URL is returned and a warning is logged.
- The JPEG quality uses the `wp_editor_set_quality` filter (82 by default).

## Generated files

The generated files are deleted with the attachment, and when its thumbnails are regenerated (i.e. with `wp media regenerate`).
